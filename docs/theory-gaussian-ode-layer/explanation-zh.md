# 从一个平面高斯分布，理解最优去噪、速度场和原版 P

这里先完成数学推导，没有启动训练。完整证明与适用条件见 [derivation.md](derivation.md)，核验结果见 [math-checks.json](math-checks.json)。这些是标准概率与矩阵运算的推导，不是新理论或模型效果结论。

## 我们选什么数据

想象三维空间里，干净数据全部落在一个平面上。平面内是椭圆形的高斯分布：

```text
x1 ~ N(0,4)
x2 ~ N(0,1)
x3 = 0
```

噪声 e 的三个方向都是标准高斯。训练输入沿用 JiT 的形式：

```text
z = t*x + (1-t)*e
```

这个例子保留了我们关心的差别：数据只有两个内在维度，噪声有三个维度。旋转整个平面不会改变结论。

## 最优去噪器是怎么算出来的

用平方误差预测 x，最优答案是 `E[x|z,t]`：在看到 z 后，对所有可能的干净样本求条件平均。条件平均使预测残差与任何仅依赖 z 的函数正交，因此任何其他预测都会在这个最低误差上增加一项非负误差。

高斯条件分布可以精确计算。在干净数据方差为 lambda 的一个方向上：

```text
c = t^2*lambda + (1-t)^2       # 当前输入的方差
最优图像预测 = [t*lambda/c] * z
```

若 lambda=0，这个方向的预测直接为零：我们知道它完全来自噪声。

## 最优速度场是什么

随机配对的训练速度标签是 `x-e`。网络无法从 z 唯一恢复这一对 x、e，所以最优速度也是条件平均。由插值关系可得：

```text
最优速度 = (最优图像预测-z)/(1-t)
         = [(t*lambda-(1-t))/c] * z
```

在 t=0.5 时，我们的三维例子给出：

```text
最优图像预测 = (1.6*z1,  z2,  0)
最优速度     = (1.2*z1,   0, -2*z3)
```

第一个方向正在扩张，第二个方向当前不动，垂直平面的方向在收缩。因此，统一要求物理速度场在所有方向收缩，会排除这个简单问题的正确答案。

图像预测的 1.6 也不是凭空放大信号：输入 z 中，干净信号本来就乘了 t。在把输入先除以 t 的另一套坐标下，高斯去噪增益位于 0 和 1 之间。讨论谱约束时必须说明坐标。

## 图像预测与真正的生成终点不同

最优图像预测是在平均可能的干净样本。真正的生成过程则沿最优速度场移动；在方差 lambda 的方向上，其从时间 u 到 t 的精确缩放是：

```text
sqrt(c(t)/c(u))
```

例如 t=0 时，图像条件平均为零，但一份具体噪声的生成终点通常不为零。直接输出条件平均与一次走到生成终点，是不同的任务。

## 原版 P 在什么情况下能对上

先作一个明确的简化：把一层直接放在数据空间，输入就是 z，输出就是干净图像预测，并且内部门控 s 固定。记最优图像矩阵为 A(t)，最优速度矩阵为 B(t)。上面已经证明：

```text
A(t) = I + (1-t)*B(t)
```

K=1 原版层是：

```text
out = (I+sP)*z
```

于是固定时间上，精确对应关系是：

```text
P = [(1-t)/s] * B(t)
```

这说明 P 确实可以与速度矩阵建立联系，但条件包括：单层、数据坐标、图像输出、固定时间、固定门控。实际 Transformer 中的隐藏 P 不能自动获得这个解释。

原版默认 K=2 时，必须重新求解：

```text
I+sP+(sP)^2/2 = A(t)
```

不能继续令 P 等于上面的缩放速度矩阵。它们是不同的参数化。

## K=2 暴露出的具体问题

当 P 对称时，每个方向的输出增益为：

```text
1+q+q^2/2 = 0.5 + (q+1)^2/2 >= 0.5
q = s * P在该方向的特征值
```

因此，这种单层无法把垂直平面的方向清零。更负的特征值也不一定收缩更多：q=-4 时，二阶多项式输出增益是 5，真正的指数增益只有约 0.018。

这个 0.5 下界只适用于实标量方向或对称 P。一般实矩阵可以有复共轭特征值，例如：

```text
Q = [[-1,-1],[1,-1]]
I+Q+Q^2/2 = 0
```

所以不能把限制 P 为对称矩阵当成无代价的稳定化。它会改变原版层能够表示的函数。

还有一个独立问题：真实速度矩阵 B(t) 随时间改变。外部轨迹的二阶项是 `B(t)^2+B'(t)`，不是只有 B(t)^2。原版内部的 P^2 项本身不构成对生成轨迹的二阶精度保证。

## 一个固定 P 为什么还不够解释整个时间过程

数据方向的速度会从收缩变成扩张，法向速度则持续收缩。一个固定 P 乘正标量 s(t)，无法让不同方向这样分别改变符号。

更严格地说，对这个具有精确零方差方向的高斯，单个固定 P、任意有限 Taylor 阶数和一个连续标量门控，都不能在一段时间内精确表示整个最优图像预测族；证明见英文推导第 9 节。这个结论只针对直接作用在数据空间的单层，不能推广成整个 ODEFFN 或 JiT 不可用。

原版输入门控还会为真实 Jacobian 增加一项：

```text
J = Taylor矩阵 + [P*T_(K-1)(sP)*h] * grad(s)^T
```

因此，只看 P 的特征值也不能完整描述层的放大、收缩和方向变化。

## 这给下一步什么依据

最有依据的问题是：如何把数据的几何方向与随时间改变的增益联系起来。对于各向同性的平面高斯，最优解已经能写成“固定子空间投影 × 时间系数”；速度则是单位矩阵和投影矩阵的两个时间系数组合。

但这个简单目标是线性的，普通时间条件线性层就能表达它。它适合校准 P 的解释与表示能力，不适合用来宣称 ODE 架构优越。现阶段还没有从这些公式推出一个应当优于 SwiGLU 的新设计，因此不据此启动新一轮训练。

真正进入下一项实验前，应明确：改动解决的是原版的表示限制，还是在相同函数类里改善优化；并给出普通线性或残差参数化无法同样解释的可检验预测。这里先把这条边界推清楚。
