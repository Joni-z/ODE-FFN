# Single-factor complete-field gradient readout

Registered 2026-10-26 before training outcomes. Preserve the original professor scalar K2 ODEFFN, two solves, intermediate SiLU, independent clocks, width64/depth3, time FiLM, normalization and vector output head. Cross the raw vector field versus the gradient of Phi=.5*x dot G with three backbones: ODE K2, SwiGLU128 and SwiGLU192. Add one direct SwiGLU384 control, fixed in advance to account for the gradient readout's extra inference work. This is seven arms on Gaussian2D, Ring8 and Product16: 21 cells. No width is chosen using quality outcomes.

All arms use seed0, 5000 updates, batch512, AdamW3e-4/weight-decay0/clip1, cached-bank independent Gaussian/target pairing and uniform time. The original common input, conditioning, norm, head tensors and Fourier buffer are copied from the same ODE reference. For each backbone its direct/gradient raw tensors and RNG draws match exactly. Initial complete velocities are zero in both modes, but hidden functions and output-head parameter responses generally differ; do not claim NTK pairing. No distillation, privileged label, derivative loss, preconditioning, new bypass or scalar-energy network is added.

New runs use the unchanged parent training draws and evaluation banks from recurrent_depth_20261026. Direct ODE/Swi128/Swi192 serve as compatibility controls; compare all four model/optimizer/RNG checkpoints at 0/1000/2500/5000 against their actual native-final parent history. Such reruns are compatibility evidence, not independent repetitions. Data stream hashes and checkpoint buffers are retained. Every raw generator P and activation diagnostic is still logged.

Before formal launch verify: exact affine readout formula; whole-model gradient/Jacobian symmetry; finite-difference mixed parameter derivatives with nonzero heads; batch independence; no_grad versus ordinary evaluation agreement; actual optimizer updates to P/controllers; native direct behavior; complete initial state pairing; three-update train/checkpoint/reload on the native host. Count actual aten matrix operations for both velocity evaluation and one training loss/backward, including the input derivative, and measure isolated one-thread preflight timing on deterministic inputs. Counts of only the G forward are insufficient. The 384 baseline is retained even if its cost is not exactly equal; no post-hoc exact-match claim is allowed.

Numerical symmetry control: the maximum per-input ||J-J^T||_F/max(1,||J||_F) must be at most1e-4 in native float32 panels, and1e-10 in independent float64 replay. Investigate any failure without changing an architecture-quality threshold.

Formal primary endpoint is full existing random-time validation oracle MSE. Also retain five fixed-time 512-input predictions and full velocity input Jacobians, symmetric/skew error decomposition, Heun32 SW2 with 2048 common starts/targets, costs, training loss, clipping, all P trajectories and ten-second process telemetry. No test bank is opened for selection; fixed bank checksums are read only to validate data integrity.

It must improve its direct parent by at least5% on a nonlinear task, beat every tested generic reference's primary field MSE by at least10% on that task, stay within5% of the best generic on the other tasks, and have Jacobian error and SW2 within10% of the best generic on both nonlinear tasks. Include all gradient generic controls and the larger direct baseline. The same arm must meet every condition. Report actual parameters/matrix work and latency; no matched-compute benefit is claimed unless supported by counts and measured throughput.

If no candidate qualifies, stop this conservative-readout setting without scalar-potential variants, gradient multipliers, distillation, preconditioned heads, optimizer/step-size, extra energy penalties or longer-training rescue. A generic gain is a baseline result, not an ODE-specific success. Exact zero curl is an implementation property, not an acceptance criterion.
