# Measurement and reproducibility scope

The main experimental units are21 deterministic trained functions, seven arms on three tasks. Model initialization seed0 and the existing independent data-generator stream are preserved. Input coordinates, five repeated times, six matrices and checkpoints are not independent training repetitions. No significance test or broad training-distribution claim is made.

Primary MSE is the elementwise mean error against the full existing uniform-time population-oracle bank. The training labels remain cached-bank independent pair velocities. The oracle is not supplied for fitting. Jacobian error is mean squared Frobenius distance on five512-input panels, then averaged over time. This has a different normalization from elementwise field MSE. Heun32 uses2048 common source samples and validation targets; SW2 uses128 fixed slice directions. No fresh holdout is opened.

The direct ODE, SwiGLU128 and SwiGLU192 histories reproduce all four actual parent checkpoints exactly, including optimizer states, runtime buffers, data RNG, Torch RNG and input hash chains. The36 state comparisons verify compatibility; they are not independent extra runs. All three5000-step input streams were independently regenerated from the training banks and checked at all snapshots. Direct/gradient initial states and nonpersistent Fourier buffers are paired for each backbone.

Actual matrix work is counted through aten matrix operations, including the input derivative and mixed-derivative loss backward. Nonlinearities, normalization, pointwise products, reductions and framework overhead are excluded. This is explicitly not a latency count. Preflight timing measures ten batch512 forward evaluations after three warmups at initialization, one CPU thread; the formal jobs run concurrently and their wall times are not isolated benchmarks.

The complete symmetric/skew CSV includes all21 models and five times. The target oracle is symmetric. Source float32 roundoff can make its component sum differ slightly from the separately accumulated full Frobenius error; the main metrics are replayed directly from the saved complete Jacobians. Independent gradient-readout verification uses all validation inputs and45 complete float64 panels, chunking only the alternative Hessian computation at64 inputs to limit memory. No gates are detached.

The144 actual P matrices across24 ODE checkpoints have their full singular spectra and real/imaginary eigenvalues recomputed from saved weights. The plotted singular maxima are summaries across layers; they are not complete-velocity stability certificates. Every generated sample array is re-integrated from the restored native checkpoint; SW2 recomputation uses NumPy float64 and its documented float32 metric tolerance.
