# 数值与统计附录

分析单位是一项完整训练；每数据集 × 模型 × K 只有 seed 0 的一个 run。3 个数据集不是同一总体的独立重复，500 步评估点也不是独立重复。

跨 seed 的 std、95% CI、p 值、Cohen d 均无法由 n=1 估计，本分析不提供这些量，也不将未定义的 std 写成 0。不做显著性检验，因此没有多重检验校正。以下百分比是观测差值，不是显著性或普适效应估计。

主比较是固定 5000 步；没有按最优 checkpoint 选择分数。全部 SW2 为 2048 样本、128 固定方向、Heun 32 / NFE 64。Moons 仅有配对 MSE，其 oracle 字段为空。
