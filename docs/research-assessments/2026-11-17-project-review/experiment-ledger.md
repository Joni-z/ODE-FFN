# Full experiment and evidence ledger

Each row is an evidence family, supporting analysis, audit or mathematical identity. It is **not** an independent training count. Source analyses can overlap the same checkpoints. The original E001–E127 records below are preserved from the finalized Report2 ledger; N records add later evidence and supplementary tables without editing that report.

Completion labels refer to the named source protocol. Failed numerical gates, partial image runs and user-canceled work remain visible. The review does not rerun training or merge different sample-bank cohorts. Full source hashes, original metadata and canonical-source coverage are in [inventory.json](inventory.json).
