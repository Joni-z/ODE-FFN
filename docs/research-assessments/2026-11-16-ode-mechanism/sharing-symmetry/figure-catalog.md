# Figure purposes and interpretation

All figures derive from the complete independently verified eight-case
cohort. PNG and PDF versions are included; exact numbers remain in JSON/CSV.

| Figure | Purpose and data | What to notice | Consequence |
|---|---|---|---|
| [generation.png](figures/generation.png) | Original/projected pooled SW2 diamonds and four paired-bank lines | Ring8 shared/stage ranking reverses; Product16 retains its gap | Reject one selected-symmetry explanation across both tasks |
| [field-decomposition.png](figures/field-decomposition.png) | Exact orbit-MSE decomposition; solid preserved, hatched removed | Ring8sharing reduces breaking error but worsens preserved error | Describe an error tradeoff rather than uniform geometry improvement |
| [partition-balance.png](figures/partition-balance.png) | Pooled eight-bin mass-L1 before/after projection | All projected masses are balanced while SW2 still differs | Partition balance alone does not determine fidelity |
| [ring-distributions.png](figures/ring-distributions.png) | Bank0, same 128 base sources in each 8 strata, 1024 dependent endpoints | Concrete distribution changes under field projection | Qualitative example; complete-bank scores determine ranking |
| [ring-paths.png](figures/ring-paths.png) | Same 16 base sources, 129 native-Heun time points | Field projection changes generated paths | Illustrate the intervention; coupling paths are not a unique target or a converged-solver claim |

No error bars appear on the diamonds: they are pooled statistics, not means.
Faint lines display the actual bank variation. The statistical appendix
defines conditional paired intervals and tests. Axis labels distinguish
Ring8 rotations from the selected Product16 reflections.

Visual QA completed: all five PNG renders were inspected for labels, legends,
point/line visibility and panel clipping. Distribution and path examples use
the same base source indices for all models. Do not use the examples as extra independent observations.
