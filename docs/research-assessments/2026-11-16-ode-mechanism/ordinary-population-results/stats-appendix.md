# Statistical scope

Eight independent paired source/target banks at fixed weights; 4,096 samples each. Report all bank squared-distance differences, means, medians and sample SDs. The registered 32 primary contrasts use exhaustive multinomial bootstrap enumeration: 6,435 count vectors, multiplicities totaling 8^8, percentile tail 0.05/64. These are conditional intervals without guaranteed coverage. They are not p-values. The secondary two-sided exact binomial sign test excludes zero differences and tests balanced sign probabilities; Holm correction covers the same 32 contrasts. Pooled SW2 is not the mean bank SW2. Dense MACs exclude pointwise operations; CPU and GPU runtimes are not compared. Formal model training used seed 0 throughout; bank draws do not represent repeated training.
