# Can invariant-conditioned hidden rotations earn their constraint?

Question: does preserving per-mode amplitudes while learning coupled phase
rates help the unchanged FM tasks at a matched budget, beyond ordinary gated
processing and the stronger existing ODE/SiLU/SwiGLU controls?
Type: exploratory architectural screen, not an exact data-generation theorem.

Hypothesis: normalized hidden features may benefit from nonlinear transport
without per-solve amplitude amplification. Pair-energy clocks offer an exact
autonomous nonlinear flow rather than freezing an arbitrary input clock.
The gate remains state-dependent through conserved quantities. This is an
inductive hypothesis; the task may instead require changing those amplitudes.

Current evidence: native K1/fixed-P quality and ordinary-control findings,
full gate-feedback derivatives, the actual normalized hidden-input boundary,
and prior integrable/action-angle constructions to review. No measured gain
supports this new constraint.

Missing evidence: complete operator/gradient validation, cost accounting,
cold matched controls and unchanged-law field/Jacobian/generation outcomes.
The intended computation must be acknowledged as an ordinary gated rotation
in its efficient implementation; no exclusive ODE mechanism is assumed.

Support: one registered candidate improves the required ordinary frontier
on the old dependence laws while passing fitting, generation, derivative and
cost guards under the same initialization stream/budget.
Falsification: only numerical validity, only a weak-old-ODE win, amplitude
conservation without quality, a norm-versus-Lipschitz confusion, or failure
of the fixed cross-law guards. Do not add a learned basis, width, order,
frequency range or optimizer sweep to rescue this setting.

Minimal next action: verify the exact flow and its ordinary same-budget
Euler/normalized-Euler controls, read the primary prior art, then nominate a
finite old-law screen only if implementation and comparison gates pass.
Decision: review and derive before selecting training.
