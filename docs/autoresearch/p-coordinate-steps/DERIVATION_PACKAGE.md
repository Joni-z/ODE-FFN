# Derivation package: an active Adam state in effective coordinates

## Target
Extend the existing constant-clock identity to arbitrary corresponding
nonzero optimizer states and verify it on real image checkpoints. This is
an algebraic proposition about one update, not a generalization theorem.

## Status
COHERENT AS STATED in real arithmetic under the assumptions below. The six real-state checks and
native prediction bridges pass; [measurements](analysis.md) retain all cases.
The result does not identify a final FID mechanism.

## Invariant object
The effective function F(theta,W) and its next parameter update, including
the optimizer state. FID is the project's outcome of interest, but this
local identity does not replace it or imply a generative advantage.

## Assumptions and notation
- Each of six FFN matrices satisfies Wj=I+cPj with fixed c>0. Use the exact
  real value represented by float32(0.6), not a recalibrated constant.
- The same minibatch loss is evaluated at the same effective function. Denote
  shared gradients by H and matrix gradients by Gj=dL/dWj.
- AdamW has the original betas, bias corrections, positive epsilon, zero
  weight decay, no AMSGrad and no optimizer-side gradient modification.
- Corresponding moments at this checkpoint satisfy mP=c*mW and vP=c^2*vW;
  shared moments and all per-parameter step counters agree. These moments
  need not be zero or have been generated by a separate W training run.
- The same P-coordinate clipping scalar is used for the exact counterpart.

## Derivation strategy and map
Affine coordinate map -> gradient pullback -> clipping scalar -> moment
recurrence -> next effective W. Then distinguish an unchanged W optimizer
and floating-point implementation from this exact counterpart.

## Main derivation
Step 1, identity: dWj=c*dPj gives gradPj=c*Gj. The shared gradient remains H.
Thus the P-coordinate norm is

```text
NP^2 = ||H||^2 + c^2 * sum_j ||Gj||_F^2.
NW^2 = ||H||^2 +       sum_j ||Gj||_F^2.
kappaP = min(1, 1/(NP+1e-6)).
```

The final line spells the native clip rule for its unit limit; it is not a
statement that clipping in the two coordinate systems agrees.

Step 2, proposition: update the corresponding moments using the same kappaP.
Linearity gives mP_next=c*mW_next. Squaring gives vP_next=c^2*vW_next.
The equal step counters preserve these identities after bias correction.
This argument starts at the transported nonzero moments as well as at zero.

Step 3, identity: multiplying the P update by c gives

```text
W_next = W - eta*c * mW_hat/(sqrt(vW_hat)+epsilon/c).
```

The elementwise operations and c>0 allow the denominator factorization.
The shared theta update stays native. Therefore direct-W Adam with matrix
rate eta*c, epsilon/c, transported moments and kappaP is the exact same
effective update. Repeating the argument preserves correspondence only while
the same data and all these conditions remain satisfied.

Step 4, distinction: native direct-W Adam instead uses eta, epsilon and
kappaW. Its moment update and effective step can differ. Even multiplying
the matrix learning rate by c alone does not generally restore equivalence.
If the gradient/moments/clipping agree and epsilon is negligible, its matrix
increment is approximately 1/c times the transported counterpart. This is
an approximation with stated conditions, not the nonzero-state identity.

## Remarks and interpretation
The fixed-clock core and ordinary SiLU have the same function class. A real
optimizer-coordinate difference can therefore exist without a new function
class or a new internal flow. The original cold controls deliberately keep
that difference. This check makes it explicit at their saved active states.

## Boundaries and non-claims
The native float32 expressions x+c*Px and (I+cP)*x reassociate arithmetic;
their complete optimization trajectories need not agree bitwise. The check
uses the literal float64 extension for the algebra and a separate native
prediction bridge. It does not claim that transporting a checkpoint equals
training a historical W model from scratch, identify a final FID cause, or
justify an optimizer rescue of a stopped experiment.

## Open risks
Gradient-route flags, parameter naming, per-parameter step counts and
clipping order must be preserved. Missing/unused parameter gradients are not
replaced by active ones. These are explicit numerical verification targets.
