# Fixed-start case notes

The panel preserves the registered first eight original Gaussian starts and
eight named 20k models; no image was selected after inspection. Start 3 has a
similar blue upper field/dark central shape across rows. Start 5 keeps a bright
diagonal patch across models. Paired feature/time outputs have small local
color and contrast changes, without a clear semantic upgrade visible in these
32×32 examples. The panel supports source correspondence, not class accuracy,
diversity, population quality or causal attribution. Full raw sample arrays
remain private and unchanged; every new image was independently replayed.
