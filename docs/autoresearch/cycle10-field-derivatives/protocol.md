# Registered complete-field derivative diagnosis

Cycle09 leaves most of the thin/clean fitted gap in the remaining residual, particularly later in time. This read-only study asks whether that residual's derivative error is mainly symmetric or skew, relative to the correct conditional reference. No architecture, P constraint, loss term, time sampling, head or solver change is selected.

Fixed cohort: all18 final cycle07 models, all five existing64-anchor panels at times.1,.3,.5,.7,.9,90panels/5760anchors. Use saved full-input oracle Jacobians and native model Jacobians. Compute conditional reference fields/Jacobians from each frozen input row space, including responsibility derivatives and all state dependencies. Bind cycle09 and prior sealed artifacts; preserve source, data, weights and evaluation unchanged.

For every anchor, in both the full128D matrix and the2D tangent-to-tangent block, save squared Frobenius energies of the total derivative error, conditional-reference displacement, remaining residual and their signed cross term. Split the remaining residual into symmetric/skew energies. Record model/reference/full-oracle skew energies separately: the conditional reference need not have zero curl. These are unnormalized matrix energies. There is no claim that the conditional field minimizes Jacobian loss or that its derivative cross term vanishes in population.

For each family/law/clean endpoint aggregate the residual energies over exactly the.7and.9panels. A symmetric share>=.8 is descriptively symmetric-dominant, <=.2 skew-dominant, otherwise mixed. Retain all families/laws/heads/times regardless of that label. Compare families through actual energies, not only fractions. No descriptive label can reverse cycle07's failed quality/transfer criteria. Also record how often the full-oracle tangent symmetric Jacobian has a positive eigenvalue above1e-8; positive expansion is not automatically a numerical defect.

Before fitted outcomes verify: analytic conditional derivatives against independent float64 automatic differentiation of literal componentwise dense Gaussian conditioning for both laws/three heads; finite differences; covariance/commutator identities; full observation against native oracle Jacobians; and explicit rank-deficient observations. Require max analytic/AD<=1e-8, full-observation<=1e-8, finite-difference<=1e-6 and energy identities<=1e-8. Register runnable source before fitted conditional derivative outcomes.

Independent audit all90panels: replay native values/Jacobians at all64anchors, compare conditional-reference fields with the sealed cycle09 formula, independently differentiate dense conditional fields at the first two anchors of every panel, and independently recompute tangent/full energies from saved matrices. Native replay is bitwise at its existing batch size. Float64 conditional fields/Jacobians require max<=1e-8. Compare per-anchor diagnostic energies with rtol1e-6/atol1e-8 and preserve failed sources/logs if any gate stops. Scientific classification thresholds do not change.

One single-thread Mac CPU process per phase,600s ceiling and per-panel PID/time/RSS monitoring. No GPU allocation or new training; Mac mini/Lenovo remain the only execution hosts. Store matrices/raw arrays/logs outside Git; publish audited tables, a readable analysis and figures. Runtime ledger keep means retained diagnostic evidence, not a new quality nominee. Seal and verify earlier files before committing; publication remains pending local authentication if unavailable.
