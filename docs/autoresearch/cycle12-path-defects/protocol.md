For each learned path x_i and frozen oracle step O_i, compute p_i=S_i(x_i), where S_i is the composition of the remaining oracle Heun steps i through31. Thus p_0 is the saved oracle endpoint and p_32 the saved model endpoint. Compute every transported defect Delta_i=p_(i+1)-p_i and local defect d_i=x_(i+1)-O_i(x_i). Do not select a favorable prefix, replace a sampler, or evaluate hybrid paths as candidate methods.

All signed contributions sum to the endpoint MSE; negative values are retained.
