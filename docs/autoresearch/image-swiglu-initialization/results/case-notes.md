# The first eight starts, without selection

The six rows and starts 0–7 were fixed before new FID extraction. All images
come from the same original Gaussian starts, native Heun128 and the 20k states.
Clipping to[-1, 1]is only the original display/feature conversion; raw sampler
states are preserved and the new raw tail fraction is 0.01118.

At start 1, default Swi86 has a conspicuous blue patch in the upper-right.
Matched Swi86 is darker there, closer in broad color to native K1, fixed-clock
and matched SiLU. At start 6, matched Swi86 instead shifts the brown region
toward yellow/green. The contrast does not support a uniformly better visual
ranking after initialization matching.

At start 3, all six retain a dark central shape against blue. At start 7,
Swi129 has more cyan horizontal structure, while the other rows retain a darker
vertical arrangement. The resolution is too coarse for reliable class labels.
These are descriptions of fixed pixels, not recognition scores or explanations
of the 12.42-point matched-Swi86 versus K1 FID gap. The full grid remains alongside the
complete 15-row endpoint comparison.
