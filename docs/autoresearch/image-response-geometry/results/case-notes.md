# Observed spaces change what the comparison means

On K1-generated states, mean negative hinge is0.03405for K1 and0.05752for
Swi86 in their own response probe spaces. Each contains genuine independently
checked negative directions. However, the learned input spaces and Krylov
frames differ. These minima cannot be subtracted to locate an exclusive
response component or explain a FID difference.

Inside their shared16-dimensional patch subspace with one identical24-vector
probe basis, the corresponding means are0.002838for K1 and0.001690for Swi86.
Neither model has a witness below-.05among the ten fixed rows from this state
origin. The same priority test fails on Swi86-generated states. This is a
finite observed-coordinate result, not proof that either complete model is PSD.

The ordinary controls prevent a stronger ODE conclusion. On K1-generated
states, SiLU131's own-space hinge0.03470is close to K1, while cold fixed P is
0.03496. These have different probe frames too. A scalar response statistic
neither isolates adaptive clocks nor reproduces the image-quality ordering.

All five times for the fixed first validation image, including both own and
shared spaces, are in fixed-image0.csv. Every stored compression is independently
checked by forward differences; maximum block error1.99e-9and maximum witness
error2.73e-10. The original tensor/buffer states remain unchanged.

The proposed priority rule therefore fails. Do not add a PSD restriction or
increase the probe dimension as a rescue. A remaining positive experimental
fact is the effect of matched initialization on ordinary SiLU. SwiGLU has not
yet received that control; an exact initial-function embedding should be checked
before another ODE-specific architecture claim.
