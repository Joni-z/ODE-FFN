## Nested-derivative audit correction

Audit-v2 then stopped on the first complete-Taylor network-Jacobian comparison. Its field values matched, but reverse-over-reverse AD through the fused native LayerNorm tangent gave a different second derivative. A float64 two-point Gaussian fixture checked the two network implementations against finite differences: the analytic formal implementation matched, whereas nested AD through fused LayerNorm did not. Switching to forward-mode JVP on that fused primitive also retained the discrepancy. This observation is specific to the installed PyTorch2.10.0 path; it is not a general library diagnosis.

Expressing normalization as explicit centering, variance, reciprocal-square-root, affine weight and bias inside the independent AD implementation resolved that fixture: complete-Taylor network Jacobians differed by3.89e-16 and frozen-gate ones by3.33e-16.
