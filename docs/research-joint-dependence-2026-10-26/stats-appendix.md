# Measurement, audit and claim scope

The unit is a fitted architecture on one target law. Five new cold fits and five historical Product16 trajectories are shown. Every model uses training seed0,5000 updates, batch512, AdamW3e-4, weight decay0, clip1, native width64/depth3 and ordinary independent-pair FM training. Time panels, coordinates and snapshots are repeated measurements of a function, not independent training replications. No p-value or training-variability confidence interval is claimed.

Primary risk uses all20000 fixed uniform-time validation inputs for each law. The secondary Jacobian measure is squared Frobenius error averaged over five512-row panels. Sampling uses2048 common starting noises,32 Heun steps/64 model calls and128 fixed projections; the targets are validation samples. No test split is used for selection. Full source/time and training-index generator conventions are recorded separately from model seed0 in the protocol.

The audit independently regenerates the100000 training and20000 validation targets, reconstructs the2048-example probe-generation stream and checks all256 persisted probe tuples. It replays two complete5000-batch training streams and every snapshot digest, validates40000 oracle rows, and restores all actual runtime buffers. It replays40 checkpoint evaluations,50 native full-Jacobian panels and10 sample outputs, and independently checks24 new P spectrum records. An additional analysis checks all48 old/new P records with NumPy and Torch SVD. All173 input bindings and158 prior documents remain unchanged.

The native conditional-GMM velocity check has maximum difference2.22e-15; independent Torch oracle Jacobians agree within6.66e-14. The target-rank supplement uses exact integer tensors, block eigenstructure and rank over prime1000003. Native mixed derivatives and small independent FFN/scalar-ODE fixtures verify the displayed formulas. This supplement was added after primary training outcomes and changes no advancement rule.

The generation case study was also added after outcomes. All five generated batches and two reference batches are included. Exact-bit membership and an independently expanded distance formula agree with the original calculations. The explicit examples use the first sign-code mismatch, not a maximal-error selection. Gaussian component noise has full support, so an invalid sign code is not an impossible observation; the empirical reference batches calibrate this diagnostic. No target component is paired with a particular source noise.

Latent low-order marginals, covariance and radial laws match, but mode count and higher-order dependence change together. The result does not isolate approximation from optimization, establish a complete-network expressivity lower bound or demonstrate ODE-specific gains. Sampling and field risks are reported separately rather than selecting whichever is favorable.
