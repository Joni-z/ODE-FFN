# Figures

1. [Field decomposition](figures/field-decomposition.png), also exported as [PDF](figures/field-decomposition.pdf). Left: all five predictors, stacked exact finite-panel components of antithetic field MSE. Right: nonlinear residual error at every fixed time. Data: field-components.csv and field-by-time.csv. Lower values are better. These are fixed-predictor diagnostics, not newly trained arms.

2. [Middle SiLU response](figures/middle-SiLU-response.png), also exported as [PDF](figures/middle-SiLU-response.pdf). All three original ODE middle activations at all five times. Left: measured additional odd-response RMS relative to the centered linear baseline. Right: the corresponding analytic upper-bound ratio. Data: middle-response.csv. Values exceeding the registered 0.10 threshold reject the uniformly-small account; large values do not imply useful nonlinear features or a causal improvement.

Both figures were visually inspected at their exported sizes. Labels and numerical values are readable, axes include all registered models/times, and no experimental measurements were generated by an image model. The plotting script reads the audited completed outputs and exports PNG/PDF versions.
