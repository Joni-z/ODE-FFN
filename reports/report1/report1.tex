\section{The project, in short}

This project asks whether a feed-forward block built from a learned dynamical operator is
better suited to flow matching, which learns a velocity field transporting noise to
data~\cite{lipman}. The intended application is to replace the FFN in a JiT image
generator~\cite{jit}. Before returning to images, we use small, unconditional synthetic
problems to test what the original ODELayer actually contributes.

The main progress is a controlled comparison of constraints on $P$, gating, Taylor order,
and training budget, with SiLU and SwiGLU~\cite{swiglu} baselines. The latest stage completed
\textbf{30 training trajectories and 54 checkpoint diagnostics}; earlier runs supply the
spectral-cap comparison. The main result is mixed: ODE $K=2$ beats SwiGLU at equal updates
on all three targets, but only on Moons after matching a compute proxy. A smaller internal
Jacobian and a more accurate exponential approximation do not consistently improve generation.

\section{Checking the layer before extending it}

The professor's original layer uses a learned matrix $P$ and a scalar gate $s(h)$:
\begin{equation}
F_K(h)=T_K(s(h)P)h,\qquad T_K(A)=\sum_{k=0}^{K}\frac{A^k}{k!},\qquad
s(h)=0.2+0.8\,\operatorname{sigmoid}(g(h)/10).
\label{eq:layer}
\end{equation}
Here $g$ is a two-layer SiLU network. Each layer computes $s$ once and shares $P$ across
Taylor terms. The FFN contains two such layers with SiLU between them; at $K=1$, one layer
is simply $h+s(h)Ph$. For fixed $s$, $\exp(sP)h$ solves $dy/du=Py$ over duration $s$.
This hidden duration is distinct from generation time $t$.

\textbf{What needs control?} The exponential series converges for every finite $P$; the
issue is finite-order error and amplification. Differentiating the layer gives
\begin{equation}
J_{F_K}=T_K(sP)+[P\,T_{K-1}(sP)h]\,\nabla_hs^\top.
\label{eq:jac}
\end{equation}
A bound on $P$ therefore does not by itself control the input gate or the full velocity
network. This standard identity motivates measuring all three quantities rather than
treating $P$ as the Jacobian of the generated flow.

\textbf{Data and controls.} We use an anisotropic Gaussian with mean $(1,-1)$ and covariance
$\operatorname{diag}(0.09,4)$; eight equally weighted Gaussian modes on a radius-3 ring,
each with covariance $0.04I$; and centered two moons with noise standard deviation $0.08$.
These are specified toy distributions, not an exact paper benchmark reproduction. Each has
100,000/10,000/10,000 train/validation/test points. Training predicts $x_1-x_0$ from
$x_t=(1-t)x_0+tx_1$ and $t$, using independent Gaussian source noise, uniform $t$, and no labels.
All runs use seed 0, width 64, three residual blocks, batch 512, AdamW at $3\times10^{-4}$,
and a default endpoint of 5,000 updates.

\textbf{Evaluation.} The primary metric is sliced Wasserstein distance $\sw$ (lower is better):
the root mean squared difference of sorted projections, using 128 fixed directions and
2,048 fixed generated/target points. Sampling uses 32 Heun steps. Gaussian and Ring8 also
have analytical velocity references; Moons does not. All results are single-seed observations.

\section{E1--E2: do constraints and extra computation help?}

\textbf{E1, spectral cap.} Purpose: test whether reducing internal amplification improves
samples. We compared free $P$ with $P_{\rm eff}=P\min(1,1/\norm{P}_2)$ at $K=1,2$.
The cap lowers the full-layer Jacobian norm in all six comparisons, but improves $\sw$
in only three (Fig.~\ref{fig:ablations}a). On Ring8 at $K=2$, the Jacobian norm falls from
$3.014$ to $2.099$, while $\sw$ worsens from $0.1848$ to $0.1889$. On Gaussian, the
same intervention improves $\sw$ from $0.0674$ to $0.0656$. Thus smaller hidden-layer gain
is not a reliable performance target. The norms average 16 observed inputs per layer and
six layers; they are not global bounds.

\textbf{E2, baseline and budget.} Purpose: check whether an ODE advantage survives a
competitive baseline and a computation control. Parameter counts are close: 82,056 for ODE,
81,858 for SiLU, and 81,792 for SwiGLU. At 5,000 updates, ODE $K=2$ beats SwiGLU on all
three targets, but SiLU is better on Ring8 (Table~\ref{tab:quality}). ODE $K=2$ costs 105,152
forward linear multiply--accumulates (MACs) per example versus 80,000 for SwiGLU.
At 6,572 updates, SwiGLU matches this cumulative MAC budget and has lower $\sw$ on Gaussian
and Ring8; ODE remains better on Moons. This is not a uniform advantage. MACs exclude
backward, nonlinear, and optimizer costs, so the comparison is not a GPU-time match.

\section{E3--E5: which part of ODELayer matters?}

\textbf{E3, input versus time gating.} Purpose: test the input-dependent step size. Feeding
the same-width time embedding to $g$ preserves parameter count and initial weights but
removes the second term of Eq.~\eqref{eq:jac} at fixed $t$. The outcome is not uniformly
better (Fig.~\ref{fig:ablations}b). On Moons at $K=2$, the full Jacobian norm rises from
$2.334$ to $2.509$ despite the zero gate-derivative term; $\sw$ changes from $0.02708$
to $0.02663$. Retrained $P$ and gate values can compensate. This changes gate inputs and
optimization as well as the derivative term, so it is not a pure derivative intervention.

\textbf{E4, Taylor order.} Purpose: test whether a more accurate hidden ODE solve helps.
We trained input-gated models with $K=1,2,4,8$. Going from $K=4$ to $K=8$ adds
\textbf{63.7\%} forward linear MACs, yet changes each target's $\sw$ by less than
\textbf{0.2\%}. On Ring8, exponential-action discrepancy falls from $2.55\times10^{-3}$
to $1.82\times10^{-6}$ (Fig.~\ref{fig:ablations}c), while $\sw$ only changes from
$0.17518$ to $0.17483$.

\Needspace{3\baselineskip}
\noindent Gaussian $K=1$ also generates better than $K=2$ despite being less
accurate against the exponential. Higher order can help---Ring8 improves from $K=1$ to
$K=4$---but exponential accuracy alone does not explain the results.

\textbf{E5, what $P$ learns.} Purpose: inspect training dynamics rather than only the final
score. Across the three targets and four orders, the six-layer mean largest singular value
rises from about $1.109$ to $1.715$--$1.862$, while stable rank
$\norm{P}_F^2/\norm{P}_2^2$ falls from $17.37$ to $8.31$--$9.40$
(Fig.~\ref{fig:trajectories}a--b shows $K=2$). The $K=4$ and $K=8$ trajectories nearly
overlap. Energy concentrates relative to the strongest direction, without implying a loss
of algebraic rank. Flattening the spectrum could therefore remove useful direction selection.

\section{Case study: fitting error is not sample quality}

On Ring8, SwiGLU has lower aggregate oracle velocity MSE than ODE $K=2$
($0.01681$ versus $0.02871$), yet worse generation at equal updates. Relative to SiLU,
it fits $t\in[0.7,0.8)$ better ($0.0256$ versus $0.0690$), but $t\in[0,0.1)$ worse
($0.0250$ versus $0.0141$; Fig.~\ref{fig:trajectories}c). Error timing is a candidate
explanation, not a demonstrated cause. Increasing Heun steps from 32 to 256 preserves
the principal Ring8 ranking, weakening a solver-only explanation.

Endpoint sensitivity also limits the budget comparison: Ring8 SiLU changes from $0.1631$
at update 5,000 to $0.2258$ at 5,024. We retain preselected endpoints, not best test scores.
One seed and repeated test-set inspection limit the conclusions. These toy models have no
attention and predict velocity, unlike JiT's image prediction; image benefits remain untested.

\section{Hypotheses for the next two weeks}

\begin{enumerate}
\item \textbf{Hypothesis:} $K=4$/$K=8$ similarity mainly reflects sufficient evaluation accuracy.
\textbf{Test:} freeze checkpoints and vary only the evaluation order or use $\exp(sP)$.
\textbf{Expected:} $K=4$ and $K=8$ substitutions have little effect on velocity and samples.
Large changes would instead suggest compensation during training.
\item \textbf{Hypothesis:} operator geometry matters beyond eigenvalue magnitude.
\textbf{Test:} vary non-normality at matched spectral radius, then repeat after matching
spectral norm; measure polynomial and exponential gain on common probes.
\textbf{Expected:} some gain differences remain after norm matching; disappearance would
favor scale as the simpler explanation.
\item \textbf{Hypothesis:} input gating adds more than a learned scalar scale.
\textbf{Test, if this direction is selected:} compare the original gate with fixed $s=0.6$
and a learned scalar per layer, retaining seed 0, both baselines, and compute accounting.
\textbf{Expected:} an input-gate benefit survives a validation-based endpoint rule fixed
before training. These are proposed tests, not completed results.
\end{enumerate}
