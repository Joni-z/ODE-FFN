# Report2 numerical scope

The report uses exact completed configuration endpoints and recorded
trajectories. It performs no new inferential tests. Optimizer/rate settings,
layers, time points and checkpoints are not independent replications.
Field MSE and test SW2 remain separate, and the latest comparisons use the
fixed20k endpoint. The5%continuation margin was registered before outcomes;
it is not a significance threshold.

All latest eighteen endpoints and ten archived reference states/samples passed
the native replay checks. The reporting script checks every selected numeric
value against its primary CSV row and file hash. It also preserves verification
of the older extracted values and historical attempt-ledger source identities.
Report1 and protected experiment/code paths are checked against the recorded
baseline. Reporting validation does not claim a new rerun of all historical
models. No FID above the project's baseline-quality gate is used to rank FFNs.
